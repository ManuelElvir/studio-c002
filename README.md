# Studio C002 — maquette 3D

Maquette 3D interactive de l'aménagement du studio (35 m²), réalisée avec three.js.

**Démo :** https://<ton-utilisateur>.github.io/studio-c002/

## Utilisation
- Glisser pour tourner, pincer ou molette pour zoomer.
- Barre du bas : vues par zone (entrée, lecture, coin nuit, repas, bureau, cuisine, salle d'eau, WC).
- En haut : ambiances Jour, Soirée, Cinéma et Travail.

## Palette
Blanc (principal), chêne (secondaire), terre cuite (accent).

## Contraintes
Logement en location : aucun perçage, tout est posé, à pression ou adhésif repositionnable.

## Mise à jour

```bash
git add index.html && git commit -m "Description du changement" && git push
```
